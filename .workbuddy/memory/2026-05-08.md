
## Swagger SwaggerGeneratorException 修复 (AttachmentsController)

**问题**: Swashbuckle.AspNetCore.SwaggerGen.SwaggerGeneratorException: Error reading parameter(s) for action AttachmentsController.Upload as [FromForm] attribute used with IFormFile

**根本原因**:
1. Program.cs 引用了 FileUploadOperationFilter 但文件不存在
2. Swashbuckle 6.x 对同一 action 方法中混用 IFormFile + 其他 [FromForm] 参数支持有限

**修复方案**:
1. 创建 Filters/FileUploadOperationFilter.cs 实现 IOperationFilter
2. 将 Upload 和 UploadBatch 的散列 [FromForm] 参数改为封装 DTO 类 (UploadAttachmentRequest / UploadBatchAttachmentRequest)，DTO 中包含 IFormFile 属性

**修改文件**:
- H:\IoTPlatform\Filters\FileUploadOperationFilter.cs (新建)
- H:\IoTPlatform\Controllers\AttachmentsController.cs (重构上传参数)

## 后端附件上传 500 错误修复

**问题**: 前端上传附件后端返回 500 Internal Server Error

**修复项**:
1. **uploads 目录不存在**: 创建 `H:\IoTPlatform\uploads` 目录
2. **UploadPath 改为绝对路径**: `appsettings.json` 中 `"FileStorage:UploadPath"` 从相对路径 `uploads` 改为 `H:\IoTPlatform\uploads`
3. **FileStorageService DI 未注册**: Program.cs 添加 `builder.Services.AddScoped<FileStorageService>()`
4. **增强日志和错误处理**: FileStorageService.cs 添加详细日志、try-catch 包裹文件保存/数据库保存、失败时清理已上传文件
5. **自动数据库迁移**: Program.cs 启动时添加 `context.Database.Migrate()` 确保 Attachments 表存在
6. **CS1503 编译修复**: `.Concat()` 返回 IEnumerable<char>，需 `.ToArray()` 转 char[] 给 `string.Split()`

## 前端区域管理改为真实 API 调用

**问题**: AreaManagementPage.tsx 的增删改操作全部是本地 state 操作（setAreas），没有调用后端 API

**改造内容**:
- **handleAddNode**: 从直接 setAreas 改为调用 `AreaContext.addArea()` -> `areaApi.createArea()` POST /areas
- **handleEditNode**: 从直接修改 state 改为调用 `AreaContext.updateArea()` -> `areaApi.updateArea()` PUT /areas/{id}
- **handleDeleteNode**: 从直接 filter 改为调用 `AreaContext.deleteArea()` -> `areaApi.deleteArea()` DELETE /areas/{id}
- **新增 submitting 状态 + Loader2 动画**: 所有 CRUD 操作显示加载中状态
- **新增 actionError 状态**: API 错误信息在弹窗内展示（如删除时有子区域/设备的后端校验错误）
- **侧边栏树改用 areaTree 数据源**: 有正确的父子层级关系（而非 flat areas）
- **列表表格增加类型、设备数列**
- **删除提示文案改为准确描述**: "如果该区域下存在子区域或已绑定设备，删除将失败"

**关键依赖链**:
```
Page -> AreaContext (addArea/updateArea/deleteArea) -> areaApi -> httpClient -> 后端 /api/v1/areas/*
```
