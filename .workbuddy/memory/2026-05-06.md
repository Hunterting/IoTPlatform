# 2026-05-06 工作记录

## 系统架构分析

**任务**：对 IoT SaaS 多租户平台进行架构可行性分析，并规划演进路线。

**分析结论**：
- 架构为 5 层分层单体（客户端接入 → 安全 → 业务服务 → 实时通信/协议 → 基础设施）
- 技术栈：.NET 8 / EF Core 8 / MySQL / Redis / MQTTnet / SignalR / Serilog
- 多租户策略：AppCode 行级隔离 + JWT Claim 传递 + Global Query Filter（IHasAppCode 接口）
- 协议支持：MQTT、Modbus TCP/RTU、OPC-UA（HTTP Polling 待实现）
- 已识别风险：Global Query Filter 静态表达式问题、MQTT Singleton 资源争抢问题

**演进路线**：
- P1（近期）：时序数据库、RabbitMQ、限流熔断、软删除审计
- P2（中期）：多节点部署、读写分离、容器化 K8s、全链路追踪
- P3（长期）：按业务域拆分微服务
