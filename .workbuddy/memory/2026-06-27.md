## Phase 3 完成：安圣设备发现与离线检测

### 新增 3 个文件
- `Services/Interfaces/IAnShengDiscoveryService.cs` — 接口（OnDeviceOfflineAsync, OnDeviceOnlineAsync）
- `Services/AnShengDiscoveryService.cs` — BackgroundService 实现：
  - ExecuteAsync 主循环：每 5 分钟扫描 DiscoveredAnShengDevice 表未认领设备
  - ScanUnclaimedDevicesAsync：按 AppCode 匹配活跃 ProtocolConfig → 获取适配器 → adapter.SendCommandAsync("getDevInfo")
  - OnDeviceOfflineAsync：Will 事件回调 → 更新 DiscoveredAnShengDevice.LastSeenAt=null + Device.Status="offline"
  - OnDeviceOnlineAsync：数据到达回调 → 新建/更新 DiscoveredAnShengDevice 记录 + LastSeenAt + 同步 Device.Status="online"
  - 内存缓存 _onlineStatus ConcurrentDictionary 快速查询在线状态
  - 订阅 AnShengMqttProtocolAdapter.DeviceWill 静态事件
- `Infrastructure/Protocol/AnSheng/AnShengWillEventArgs.cs` — Will 事件参数（Imei, Payload, ReceivedAt, AppCode）

### 修改 2 个文件
- `Infrastructure/Protocol/Adapters/AnShengMqttProtocolAdapter.cs` — 新增 `static event DeviceWill`；HandleWillMessage 触发事件
- `Services/ProtocolConfigService.cs` — 注入 IAnShengDiscoveryService（可选）；OnProtocolAdapterDataReceived 中：
